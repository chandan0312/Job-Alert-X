## ✅ How to Use

1. Pick the right template for your post type
2. Replace all `[PLACEHOLDER]` text with actual data
3. Copy the **SEO Title**, **Meta Description**, and **Keywords** into the Admin Post Form fields
4. Copy the **Detailed Description (HTML)** into the Rich Content editor
5. Fill in all structured fields (Important Dates, Fee, Vacancies, Links)
